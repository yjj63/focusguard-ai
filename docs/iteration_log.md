# FocusGuard AI 关键迭代记录（AI 协作过程留痕）

> 本文档用于记录《人工智能基础与应用》课程项目从选题规划到最终部署的完整 AI 协作与多轮迭代过程，后续将整理导出为 PDF 附件提交。

---

## 节点 0：选题规划与技术架构确立
- **背景与约束**：需提交可部署在 GitHub Pages 的静态网页作品、源代码与中间过程、Word 实验报告及带迭代标注的 AI 交互记录 PDF。
- **关键决策**：
  1. 选定“AI + 视觉交互：基于浏览器端深度学习的实时专注度与坐姿健康助手（FocusGuard AI）”。
  2. 采用纯前端静态架构 + Google MediaPipe FaceLandmarker（WebAssembly 本地推理），无需后端服务器与 API Key，保护用户摄像头隐私。
  3. **防翻车设计一（同源本地化模型）**：将 `vision_bundle.mjs`、WASM 运行时与 `face_landmarker.task`（3.58 MB）直接本地化打包进 `assets/` 目录，避免国内网络访问 Google Storage 失败。
  4. **防翻车设计二（无摄像头模拟演示模式）**：内置 `DemoSimulator`，确保无摄像头设备也能完整体验五类姿态/疲劳状态检测与交互联动。

## 节点 1：v1.0 基础原型搭建
- **本轮目标**：完成双栏监测界面、MediaPipe 本地推理接入、头部欧拉角与 Blendshapes 提取、标准坐姿校准、异常持续时间防抖判定、Web Audio 声音提醒与无摄像头演示模式。
- **核心模块**：
  - `index.html` + `css/style.css`：深色仪表盘界面与响应式布局。
  - `js/analyzer.js`：从 4×4 变换矩阵提取 Pitch/Yaw/Roll，结合 `eyeBlink`、`jawOpen` 与人脸占比计算 0–100 综合专注评分。
  - `js/demo.js`：五种典型场景（标准专注、低头驼背、离屏过近、疲劳闭眼、左右走神）的实时模拟引擎。
  - `js/app.js`：摄像头/演示模式切换、本地模型 GPU/CPU 自动回退与事件日志记录。
- **验证发现的问题**：
  1. 手机无法通过 `localhost:8088` 访问本机测试服务，且普通局域网 `http://` 下手机浏览器安全策略会禁用摄像头——确认必须通过 GitHub Pages 的免费 HTTPS 完成公网部署。
  2. 仅有瞬时读数和日志，缺少**时间维度的趋势可视化**、**异常类型统计**、**算法阈值自定义**与**学习报告导出**。

## 节点 2：v2.0 增强版迭代（当前版本）
- **本轮优化目标**：补齐数据可视化、算法可解释性与用户实用闭环，显著提升作品展示度与完成度。
- **具体改进内容**：
  1. **新增 `js/charts.js`（零外部依赖 Canvas 绘图）**：
     - 实现最近 60 秒**实时专注度趋势折线图**（带 60/80 分警戒虚线与面积渐变填充）。
     - 实现**高清 PNG 学习健康报告图**生成与下载，无需任何第三方图表库或后端服务。
  2. **升级 `js/analyzer.js`**：
     - 引入三档灵敏度预设（宽松 / 标准 / 严格）及动态阈值更新接口。
     - 统计 6 类异常事件的触发频次，并基于最高频异常自动生成个性化护眼护颈建议。
  3. **升级 `index.html`、`css/style.css` 与 `js/app.js`**：
     - 新增**异常事件分类统计条**与**AI 判定灵敏度调节滑块**（低头角度、前倾距屏比例、闭眼时长实时生效）。
     - 新增 **Web Speech API 中文语音播报提醒**（支持在“中文语音播报 / 轻柔提示音 / 静音”间自由切换）。
     - 摄像头监测界面增加人脸 HUD 追踪框，提升视觉科技感。
     - 新增“生成学习报告”弹窗，支持导出 **TXT 文本报告** 与 **PNG 报告图**。
- **下一步（节点 3 / v3.0 产品化闭环）**：构建完整学习场景闭环，增加 3D 姿态可视化仪表、番茄钟、护眼引导、历史档案与双主题切换。

## 节点 3：v3.0 正式版迭代（当前版本）
- **本轮优化目标**：将工具从“单次实时检测器”升级为完整的“AI 学习专注与体态健康助手”，增强视觉直观性、长期追踪能力与演示丰富度。
- **具体改进内容**：
  1. **新增视频画面 3D 头部姿态方位仪 HUD**：在实时监测窗口右下角叠加动态姿态准星，以安全中心圈、Roll 旋转十字轴与 Pitch/Yaw 偏移向量直观呈现 AI 模型的三维头部姿态解算结果。
  2. **新增番茄专注时钟（25/15/5 分钟）智能联动**：计时结束后自动保存本次学习记录、语音播报鼓励并弹出健康总结报告。
  3. **新增 20-20-20 护眼与颈椎放松引导弹窗**：提供 20 秒远眺倒计时与三步颈椎舒缓引导，形成“监测—提醒—放松”完整健康闭环。
  4. **新增 `js/storage.js`（本地历史学习档案）**：基于 `localStorage` 持久化保存最近 12 次学习记录（时长、平均分、专注率、最高频问题），刷新不丢失且完全本地化。
  5. **新增深色 / 浅色双主题一键切换**：适配日间/夜间学习场景与不同评阅展示偏好。
- **下一步（部署与交付收尾）**：
  1. 将完整项目上传至 GitHub 并开启 GitHub Pages，在电脑和手机上验证公网 HTTPS 访问与摄像头权限。
  2. 生成 Word 版《人工智能基础与应用》实验报告（`.docx`）与带迭代节点标注的 AI 交互记录附件（`.pdf`）。
  3. 录制 1–2 分钟系统实测演示视频并打包提交。
